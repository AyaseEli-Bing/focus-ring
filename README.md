# focus ring

一个安静的专注计时器。没有框架、没有依赖、没有构建步骤，打开就能用。

![focus ring 界面](assets/preview.png)

在线使用：<https://ayaseeli-bing.github.io/focus-ring/>

## 功能

- **25 分钟专注**，完成后自动切到 5 分钟短休；每完成四轮专注，进入 15 分钟长休。
- **仪器式表盘**：60 格刻度环与红色进度弧，剩余时间一眼可见。
- **今日统计**：完成的轮数保存在本地，刷新页面不会丢失。
- **提示音**：阶段结束时轻轻响两声，可随时关闭。
- **键盘可用**：空格开始 / 暂停，R 重置，S 跳过。
- **响应式**：桌面和手机都能完整使用，并遵循系统的减少动态效果设置。

## 使用

直接用浏览器打开 `index.html`，或在目录里启动任意静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 轮次规则

| 阶段 | 时长 | 触发时机 |
| --- | --- | --- |
| 专注 | 25 分钟 | 手动开始 |
| 短休 | 5 分钟 | 第 1–3 轮专注完成 |
| 长休 | 15 分钟 | 第 4 轮专注完成 |

长休结束后，本轮进度清零。跳过专注会直接进入短休，且不计入今日完成数；跳过休息会回到专注；跳过长休会清零本轮进度。

## 快捷键

| 按键 | 动作 |
| --- | --- |
| 空格 | 开始 / 暂停 |
| R | 重置当前阶段 |
| S | 跳过当前阶段 |

## 实现说明

- 原生 HTML / CSS / JavaScript，无构建、无第三方运行时依赖。
- 剩余时间按时间戳计算，标签页切到后台再回来不会产生漂移；若在后台到期，回到页面时会立即补上阶段切换。
- 拉丁数字使用 Martian Mono（Google Fonts），中文使用系统字体；字体加载失败时自动回退到系统等宽字体，不影响使用。
- 尊重 `prefers-reduced-motion`，提供可见的键盘焦点样式与屏幕阅读器状态播报。
