# Tiny Tools

一个简洁、好看的网页小工具集合。没有框架、没有依赖、没有构建步骤，打开就能用。

## 包含应用

### focus ring

一个安静的专注计时器。

- **25 分钟专注**，完成后自动切到 5 分钟短休；每完成四轮专注，进入 15 分钟长休。
- **仪器式表盘**：60 格刻度环与红色进度弧，剩余时间一眼可见。
- **今日统计**：完成的轮数保存在本地，刷新页面不会丢失。
- **提示音**：阶段结束时轻轻响两声，可随时关闭。
- **键盘可用**：空格开始 / 暂停，R 重置，S 跳过。

[打开 focus ring →](focus-ring.html)

### clip shelf

剪贴板历史管理器。

- 自动识别 **链接、代码、颜色、邮件、图片、文本**
- 搜索、分类过滤、置顶、复制、删除
- 可开启系统剪贴板监听，自动捕获新内容
- 数据持久化到浏览器本地
- 响应式布局，桌面三栏、手机底部抽屉预览

[打开 clip shelf →](clipboard.html)

## 本地运行

用任意静态服务器启动目录，例如：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。
